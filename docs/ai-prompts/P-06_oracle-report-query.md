## 1. Prompt Template

```text
เขียน Oracle SQL สำหรับรายงานที่ [n] ตามข้อกำหนด [text]
ใช้ TO_CHAR, TRUNC(...,'IW'), PIVOT, LISTAGG, CASE WHEN
และอธิบายว่าควรแสดงกราฟแบบใด

ข้อกำหนดเพิ่มเติม:
1. ต้องระบุคอลัมน์ชัดเจน ห้าม SELECT *
2. ต้องใช้ bind variable สำหรับพารามิเตอร์ (เช่น :year, :route_id) — ห้ามต่อสตริง
3. ต้องอธิบายว่าผลลัพธ์เป็นตัวเลขหรือข้อความ และควรแสดงกราฟแบบไหน
   (แท่ง / เส้น / วงกลม) พร้อมเหตุผล
4. ห้ามใช้ฟังก์ชันของ MySQL เช่น DATE_FORMAT, IFNULL, GROUP_CONCAT
   ต้องใช่ TO_CHAR, NVL/COALESCE, LISTAGG
5. ต้องระวังเรื่องเขตเวลาและ NULL — ถ้าข้อมูลเป็น NULL ให้แสดง 0 หรือ '-'
   เฉพาะกรณีที่ข้อกำหนดระบุ และต้องอธิบายเหตุผล
6. ต้องรัน query ได้จริงบน Oracle และแนบผลลัพธ์จริงมาให้ตรวจ
7. ถ้าใช้ PIVOT ต้องอธิบายว่าเหมาะกับกรณีไหน และเขียนทางเลือกแบบ CASE WHEN ไว้ด้วย
```
