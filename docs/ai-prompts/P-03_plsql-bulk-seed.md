## 1. Prompt Template (ตาม 18.1.3)

```text
เขียน PL/SQL block ใส่ [จำนวน] แถวลงตาราง [table] ด้วย FORALL + BULK COLLECT
ให้ข้อมูลสมจริงหลากหลายตามตัวอย่างในเอกสาร

ข้อกำหนดเพิ่มเติม:
1. ต้องไม่มีชื่อบุคคลจริง ใช้ชื่อสมมติเป็นภาษาไทย เช่น "สมชาย ใจดี" (AR-03)
2. ห้ามสร้างข้อมูลที่ขัดกับ Business Rule BR-01…BR-12
   - **BR-06: seats ต้องอยู่ในช่วง 1…4 ต่อ 1 การจอง** (ไม่ใช่ 1…9 —
     9 คือจำนวนที่นั่งของรถ ซึ่งเป็น `vehicle_type.capacity` ไม่ใช่จำนวนที่จองได้)
   - **BR-07: เหลือที่นั่งพอ** ต้องเช็คที่ Service Layer (ล็อก `schedule` ก่อนแล้ว
     `SELECT ... FOR UPDATE NOWAIT`) — ใช้ `NVL(SUM(...),0)` เพราะ Oracle คืน NULL
   - travel_minutes / total_minutes ต้อง >= 0
3. ใช้ MOD(multiple_of) ให้เกิด id หลากหลาย ไม่ใช่ 1,2,3 ติดกัน
4. ใส่ NULL ในคอลัมน์ nullable บางส่วนเพื่อทดสอบจุดแยก NULL
5. ปิดท้ายด้วย COMMIT และ query นับแถวจริง
6. ต้อง ROLLBACK ได้ — ห้ามใช้ DDL ในบล็อก (DDL จะ commit อัตโนมัติ)
7. ถ้าจำนวนแถวที่ใส่ไม่ครบ ให้รายงานว่าข้ามเพราะอะไร
```
