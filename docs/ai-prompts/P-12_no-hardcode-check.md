## 1. Prompt Template

```text
ตรวจโค้ดทั้งโปรเจกต์ว่ามีการ hardcode สิทธิ์/บทบาทหรือไม่
(เช่น role == 'admin', if (isAdmin)) รายงานตำแหน่งที่พบ

ข้อกำหนดเพิ่มเติม:
1. ต้องรายงานเป็นตาราง: ไฟล์ | บรรทัด | โค้ดที่พบ | ทำไมถึงถือเป็นการ hardcode
2. ต้องแยก 2 กรณี:
   - ผิดจริง  = ตัดสินสิทธิ์จากค่าในโค้ด  → ต้องแก้ให้มาจากตาราง
   - ไม่ผิด  = แค่เปรียบเทียบเพื่อแสดงผล เช่น ชื่อบทบาทที่แสดงบนหน้าจอ
     → อนุญาต แต่ต้องอธิบายเหตุผล
3. ต้องตรวจทั้งฝั่ง backend (Node.js) และฝั่งแอป (Flutter)
4. ต้องตรวจคำสั่ง grep ที่ใช้จริง และแนบผลลัพธ์
5. ต้องรายงานสรุปว่า "ผ่าน" หรือ "ไม่ผ่าน" ชัดเจน
6. ห้ามแก้โค้ดให้อัตโนมัติ — รายงานอย่างเดียว แล้วให้นักศึกษาเป็นผู้ตัดสินใจ
```

### 🔎 คำสั่งตรวจที่แนะนำ

```bash
# ฝั่ง backend
grep -rnE "role\s*===?\s*['\"]|isAdmin|isStaff|role\s*==\s*['\"]" --include=*.js --include=*.ts .

# ฝั่ง Flutter
grep -rnE "role\s*==\s*['\"]|isAdmin|isStaff" --include=*.dart .

# secret ที่อาจหลงเหลือ
grep -rniE "password|secret|api[_-]?key|token\s*=" --include=*.js --include=*.dart . | grep -v "process.env"
```
