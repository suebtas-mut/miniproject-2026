## 1. Prompt Template

```text
สร้าง middleware ตรวจสิทธิ์จากตาราง role_permission + app_role + permission
แบบ dynamic ไม่ hardcode

ข้อกำหนดเพิ่มเติม:
1. ⛔ ห้ามมี if (role === 'admin') · isAdmin · role == 'staff' ในโค้ดทุกรูปแบบ
   สิทธิ์ต้องมาจากตารางเสมอ — เพิ่มบทบาทใหม่แล้วต้องใช้งานได้โดยไม่แก้โค้ด
2. Query permission ของ user ครั้งเดียวต่อ request แล้ว cache ใน req.user
   เพื่อไม่ให้ยิงฐานข้อมูลซ้ำหลายครั้ง
3. ต้องรองรับหลายบทบาทต่อ 1 คน (UC-10) — สิทธิ์คือผลรวมของทุกบทบาทที่คนนั้นมี
4. ใช้ bind variable ทุก query และระบุคอลัมน์ชัดเจน ห้าม SELECT *
5. โยงกับ login ที่ UC-01 และ token ที่เก็บใน flutter_secure_storage
6. ถ้าไม่มีสิทธิ์ ต้องตอบ 403 พร้อมรหัสสิทธิ์ที่ขาด — ห้ามตอบ 404
7. ห้าม hardcode รายชื่อ permission เป็น string ในโค้ด — ให้ดึงจาก
   ค่าคงที่ที่ map กับค่าในตาราง และมี test ยืนยันว่าตรงกัน
8. ต้องมี test ยืนยันว่าผู้ใช้ที่ไม่มีสิทธิ์ถูกปฏิเสธจริง
```
