## 1. Prompt Template

```text
สร้างหน้าจัดการ [entity] แบบ DataTable + PaginatedDataTable + Master-Detail
ที่ใช้งานได้ทั้งมือถือและแท็บเล็ต

ข้อกำหนดเพิ่มเติม:
1. ⛔ ห้ามสร้างเว็บ — ใช้ Flutter เท่านั้น
2. ต้องแบ่งหน้าจริงที่ฝั่ง server (อย่าดึงข้อมูลทั้งหมดมาแล้วตัดในเครื่อง)
3. ต้องมี Master-Detail: แตะแถวที่เลือกแล้วดูรายละเอียดด้านข้าง/ด้านล่าง
4. บนมือถือ DataTable ต้องล้นได้ (แนวนอน) ไม่ล้นจอจนกดไม่ได้
5. ต้องมี 4 สถานะ: loading / สำเร็จ / ว่าง / ผิดพลาด พร้อมปุ่มลองใหม่
6. ปุ่มเพิ่ม/แก้ไข/ลบ ต้องยืนยันก่อนลบ และแสดงข้อความสำเร็จ/ไม่สำเร็จ
7. ทุก action ต้องผ่าน middleware สิทธิ์ของ P-05 ห้ามซ่อนปุ่มด้วย if (isAdmin)
8. ห้าม hardcode URL — ใช้ --dart-define
9. ต้องแสดงวันที่เป็นรูปแบบไทย และแปลงเป็นวันที่ไทยให้ถูกต้อง
10. ถ้าเรียก API ล้มเหลว ให้แสดงข้อความที่ผู้ใช้เข้าใจ ไม่ใช่ error ดิบ
```
