## 1. Prompt Template

```text
ตรวจโค้ด [file] เน้น security, error handling, performance,
transaction/locking, จุดผิดพลาดเชิงตรรกะ

ข้อกำหนดเพิ่มเติม:
1. ต้องอ้างอิงบรรทัดที่พบปัญหา (file:line) ทุกข้อ ห้ามพูดกว้าง ๆ
2. ต้องแยกเป็น 3 ระดับ: วิกฤต (ต้องแก้ก่อน merge) / ควรแก้ / แนะนำ
3. ต้องตรวจ 5 ด้านเสมอ:
   - security : SQL injection, secret ในโค้ด, hardcode สิทธิ์
   - error handling : มีทุกเส้นทาง error ถูกจัดการ? ส่งรายละเอียดภายในออกไปไหม
   - performance : SELECT *, ไม่มี index, N+1 query, ดึงข้อมูลทั้งหมด
   - transaction : BEGIN/COMMIT/ROLLBACK ครบไหม, ปิด connection ไหม
   - logic : ตรงกับ Business Rule BR-01…BR-12 ไหม
4. ⛔ ต้องตรวจด้วยว่ามี syntax ของ MySQL หลงเหลือหรือไม่
5. ต้องตรวจว่ามีโค้ดเว็บ (React/HTML) หลงเหลือหรือไม่ (AR-11)
6. ห้ามเสนอให้เขียนโค้ดใหม่ทั้งก้อน — ให้เสนอเป็นข้อแก้ไขเฉพาะจุด
7. ถ้าไม่พบปัญหา ให้บอกตรง ๆ ว่าไม่พบ ห้ามกุข้อความเตือนปลอม ๆ
```
