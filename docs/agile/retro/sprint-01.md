## 3. เหตุการณ์ / เรื่องเฉพาะของ Sprint นี้

### 🥇 Requirement ผิด 1 จุด — `chapter-18` สั่งดัชนี 9 ตัว แต่สร้างได้ 8

`ix_schedstop_sched_seq` ซ้ำกับ unique index `uq_sched_seq` ที่ Oracle สร้างให้เอง → `ORA-01408`

**สิ่งที่ทำถูก:** คง 8 custom index ไม่ใช่ยกชั้น index ทับเพื่อให้ตรงตัวเลขในเอกสาร
**สิ่งที่ต้องระวัง:** ตัวเลขใน Requirement ไม่ได้ถูกต้องเสมอ — **ต้องรันจริงเสมอ แล้วค่อยแก้เอกสารทีหลัง**

### 🥈 T-005/T-006 ทำล่วงหน้าจนต้อง "ยืนยันใหม่"

ทำ ER + Data Dictionary ใน Sprint 0 ก่อน DDL จะออก → ตอนเขียน DDL จริงจึงต้องกลับมาแก้เอกสารทั้งคู่
**บทเรียน:** งานเอกสารที่ขึ้นกับผลลัพธ์ของงานถัดไป ควรจัดลำดับให้ถูก **หรือทำหลัง** ไม่ใช่ทำล่วงหน้า

### 🥉 `@agent-oracle` ผิด 6 จุดในวันเดียว

ครั้งแรกที่ AI ทำ DDL ในโปรเจกต์ → ผิด 6 จุด (ดู `sprint-01-report.md` หัวข้อ 2)
**สิ่งที่ดี:** ทุกข้อถูกจับได้เพราะ **รันบน Oracle จริง** ไม่ใช่อ่านโค้ด
**ข้อสรุป:** งาน DDL ไม่มีทางตรวจด้วยการอ่านอย่างเดียว — ต้องรัน
