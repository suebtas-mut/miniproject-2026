## 👍 สิ่งที่ทำได้ดี

- **ตัด Web ออกได้เร็ว** — ตรวจช่องว่างในเอกสารแล้วไม่มีโฟลเดอร์ `frontend-web/` ทำให้ไม่เสียเวลาสร้าง UI ทิ้ง
  และตรงกับข้อ 17.0 พอดี (บันทึกเป็น Q11 เพื่อยืนยัน)
- **Oracle เชื่อมต่อได้จริงภายในวัน** — ตรวจ `healthy` + `SELECT` ผ่าน + ยืนยัน `user_tables = 0`
  ทำให้ Sprint 1 เริ่มเขียน DDL ได้ทันที
- **ใช้ AI ช่วยแปลง Requirement เป็น 30 Use Case** แทนการนั่งอ่าน PDF ทีละหน้า
  → ประหยัดประมาณ 2 ชั่วโมงจากเวลาที่ประมาณไว้ 5 ชั่วโมง
- **จับ Bug config ได้ตั้งแต่วันแรก** — `DB_PASS` ไม่ตรงกับ `APP_USER_PASSWORD` และใช้ `DB_SID`
  ทั้งที่ต้องเป็น `DB_SERVICE_NAME` → ถ้าไม่ตรวจตอนนี้ จะไปเจอตอน Sprint 4 ทำ Login
- **บันทึก Prompt ตั้งแต่วันแรก** ตาม AR-06 — ไม่ต้องย้อนมาหาทีหลัง

## 👎 สิ่งที่ต้องปรับปรุง

- **Q14 (Oracle 19c vs 21c XE) ไม่ได้ปิดตั้งแต่ต้น** — เพิ่งมาเจอตอนติดตั้งจริง
  → ควรอ่าน Requirement ด้านเวอร์ชันเทคโนโลยีให้ครบตั้งแต่ Sprint Planning

  แม้ checklist จะระบุ ⛔ ห้ามใส่ DB Password ใน Git ก็ตาม → **ต้องแก้ก่อน Push**
- **Prompt รอบแรกไม่ระบุ "ข้อเท็จจริงที่ตกลดแล้ว"** ทำให้ AI ถามกลับเรื่อง Service Name / SID
  ทั้งที่มีข้อมูลอยู่ในโปรเจกต์แล้ว → เสียเวลาไปรอบหนึ่ง (บันทึกแล้วในไฟล์ Prompt Log)

  → ต้องมีขั้นตอน `grep` ตรวจ typo ทุกครั้งหลัง AI เขียนเอกสาร
- **ตรวจภาพ Use Case Diagram ไม่ได้ด้วยตา** — AI render เป็น PNG แล้ว แต่ตรวจได้แค่ syntax
  → ต้องให้สุขสรร (ผู้ทำ Mockup ด้วย Figma) ตรวจความอ่านง่ายของผังอีกครั้งก่อน Sprint Review
