## 🟢 สิ่งที่ดีของวันนี้

1. **T-008 ปิดได้โดยไม่ต้องรออาจารย์ตอบ** — เพราะใช้หลัก "ผลบวกจริง + `TODO(Q-B)`" ตามแผนสำรองที่เขียนไว้ล่วงหน้า
2. **ทดสอบจากสคีมาว่างจริง ไม่ใช่รันทับของเดิม** — `99_drop` → `01` → `02` → `03` พิสูจน์ว่าไฟล์รันได้ตั้งแต่เริ่ม
3. **Business Rule พิสูจน์ด้วย query ไม่ใช่การดูด้วยตา** — BR-01/02/04 มี query ตรวจฝังอยู่ท้ายไฟล์ รันซ้ำได้ทุกครั้ง
4. **คำนวณเวลาให้อัตโนมัติตาม BR-01/BR-02** — ไม่ hardcode `total_minutes` และไม่ hardcode `arrive_at` แต่ใช้ correlated subquery → แก้นาทีทีเดียวทุกจุดขยับตาม
5. **Password ใน seed เป็น placeholder ที่ login ไม่ได้โดยตั้งใจ** — มี query ยืนยัน `PLAIN_PWD = 0` → ไม่มีความเสี่ยงรหัสผ่านหลุดเป็นข้อความธรรมดา (BR-SEC-1)
6. **AI นับ permission ผิดเอง (24 → 21) แต่คนตรวจจาก output จริงจึงเจอ** — เป็นหลักฐานว่า AR-05/AR-07 ทำงานจริง ไม่ใช่พิธีกรรม
7. **ข้อค้นพบเรื่องเส้นทาง 1 ถูกบันทึกไว้ในตัวไฟล์ SQL เอง** — ไม่หายไป เพราะเขียนไว้เป็นหัวข้อ 1) ของ `03_seed_front.sql` พร้อม constraint ที่ชน
