- **เส้นทางที่ 2** = 4 จุด · travel_minutes = 0 + 5 + 3 + 5 → `total_minutes` = **13**

- **รอบเวลา seed**: service_date `2026-10-01` · 09:30 / 11:00 / 13:00 / 15:00 (×2 เส้นทาง = 8 รอบ)
- **ชนิดรถ**: รถตู้ 9 ที่นั่ง / รถมินิบัส 15 / รถบัส 20
- ⚠ วันนี้ (08 ต.ค. 2026) **หลัง** วันที่ของรอบ seed → เคสจองที่ต้องการรถถึงในอนาคต
